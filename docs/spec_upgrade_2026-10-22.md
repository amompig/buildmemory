## 2. 升級（合成）

| 規則 | 內容 | 狀態 |
|---|---|---|
| 材料 | **兩棟同一種**房子（同 item_id、同一階） | ✅ |
| 消耗 | 兩棟舊的消耗掉，換一棟新的 | ✅ |
| 第一次升級 | 1×1 → 同類型的較大版本，**1×2 或 1×3 隨機**（兩者同一階） | ✅ |
| 第二次升級 | 兩棟同一種的第二階 → 同類型的 2×2 | ✅ |
| 地標（lm:*） | 暫時不能升級 | ✅；❓ 使用者還在想 |
| 升級後的外觀 | 「一般建築的較大版本」，每個 1×1 類型需要 1×2、1×3、2×2 三個版本 | ❓ 要 Design 畫 |

## 3. 給 Design 的需求

1. 每個 1×1 一般類型的升級版本。目前 1×1 共 5 種：鐵窗透天厝、老公寓、磁磚電梯大樓、小廟、日式宿舍。每種要 1×2、1×3、2×2 三版，合計 15 張 blueprint v2.2。
2. 各城市的 1×1 池，也就是每個縣市每日簽到、非精選地標會隨機出哪幾種。
3. 基礎部件清單（道路以外，例如樹、路燈）與其外觀。部件是否佔格、能不能疊在路上，也請一併定義。
4. 每日簽到裡，部件和房子的機率比例（或由使用者定）。
