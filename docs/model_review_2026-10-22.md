> 依四份文件執行：《台北地標模型：幾何語彙與模型本體檢討》《台灣建築模型：幾何語彙與模型本體檢討 Memo》《MEMO｜建築模型的立體感與線條一致性》《建築立體感與線條關係：專有詞彙與視覺分析指南》。

## 1. 先修幾何：這次對渲染契約做的系統性修正

| 檢查項 | 之前的問題 | 修正（blueprint v2.2 + 渲染器） |
|---|---|---|
| Massing | 所有屋頂都是「蓋在盒子上的色塊」（層層內縮的平板），屋頂不進剪影 | 屋頂改為真實斜面：`hip` 四坡交於脊、`gable` 兩坡 + 三角山牆、`hip2` 下簷裙 + 牆帶 + 上坡、`mansard` 斜裙 + 平頂、`swallowtail` 兩坡 + 翹脊、`oct` 八角攢尖。`roofH` 改為「45° 坡」的倍率（1 = 半短邊高） |
| Proportion | 展示比例被統一，每棟都縮到同一視覺體積 | 畫布改用**同一個顯示倍率 1.25**，只有高度超出框的 101 被縮到 1.22；相對尺度由 `size`（1×1 → 3×3）與 `zoom` 決定，不再逐棟放大填滿 |
| Projection | 等角投影本身正確（平行線不收斂） | 不動；新增的斜面仍是平行投影 |
| Facade Articulation | 柱是色條、窗是色塊、拱門是色塊 | 柱 = 0.06 格實體 block；窗 = 深色框 + 內嵌亮面；`arch` = 挖入南面的拱洞（`through` 可看穿到地面色）；`z` 讓上層跨在柱廊 / 台階之上 |
| Line Hierarchy | 所有邊等權重 | 主轉折線：每個量體的前垂直角線 1.2 px 最深色；次級：簷口板 2.5 px 深色；細節：窗框 1 px。無描邊的平面靠明暗分面 |
| Lighting / AO | 面向一致（南面亮、東面 0.86），但無遮蔽 | 出簷下加 2–6 px 的環境光遮蔽帶（簷越深越寬）；屋頂四坡分別為 1.06 / 1.0 / 0.9 / 0.8 |
| Silhouette | 無法檢查 | 每張卡右下角加純色剪影（ink 色），作為每次修改的驗收 |
| 地面板 | 田 / 埕 / 池會蓋住建築（painter's sort 以佔格排序） | `h ≤ 0.03` 的地面板一律先畫 |
| 前後次序 | 以 `c+w+r+d` 單一數值排序，長條量體（林安泰正身 3 格寬）會壓到位在它南邊的護龍 → 錯位 | 改為分離軸拓樸排序：A 整個在 B 的西 / 北 / 下方才算在後面，DFS 先畫後面的；無法分離時才用舊 key |
| 相交量體 | 嵌在正殿四角的角墩與正殿沒有分離軸，次序落回 key → 後方角墩畫在屋頂上 | 相交時比「朝觀者的延伸」：共用欄位時比南緣、共用列時比東緣 |
| 屋簷是一層 | 量體的牆 + 屋頂一起畫，所以凡是畫在正殿之後的東西（前方角墩）都會蓋在屋簷上——這是「層」的問題不是高度 | 出簷屋頂拆成獨立的繪製層：box 從簷口高度起算，所有低於簷口的量體先畫、屋頂再蓋上去。硬規則兩條：本體 → 自己的屋頂、父量體與其屋頂 → 疊在上面的子量體；遇到 L 形平面必然出現的循環時，違反這兩條的項目延後到父項之後立刻畫（總統府塔樓因此回到入口柱廊上方） |
| 裝飾 | 101 的圓徽是兩顆螢幕對齊的圓點，像眼睛 | 圓徽改為牆面平面內的古錢環（外環 + 內孔），每面一枚在基座上緣；裙樓帶窗改為每 0.9 格一段、單排；移除裙樓的門 |

## 4. 未在這一輪處理、建議給 kit.js 的事

1. **剪影辨識度是驗收門檻**：bake 後把每個房型渲染成純色 PNG（和預渲預覽同一視角），放在 `assets/previews/sil/`，PR 需附。
2. **線條權重在 three.js 的對應**：主轉折線 = `EdgesGeometry` 只取 ≥ 60° 的邊、線寬 1.2 px、ink 色 60%；次級（簷口、雨遮）靠 AO 帶，不描邊；窗框不描邊。
3. **101 的竹節**：改用 8 個 `segments` 各自 sBot 0.8 / sTop 1.1 已有外擴，若要更像「節」，在每節頂加 0.04 格厚的環（block），而不是再加面數。
4. **龍山寺 / 總統府是線條預算上限**（20–23 個 block）；其餘控制在 ≤ 16。
5. 監察院 `domeScale` 1.5 → 1.3；紅樓一樓拱廊（8 面 arch）留到 kit.js 部件層。
