- 一人開發，研究者/學生，有 Three.js 自學經驗；前作 Dies-X（React + R3F + Rapier，Cloudflare Workers/D1，Google 登入）
- 工作方式：快速迭代、零美術資產、靜態站優先（參考「台股小鎮」：index.html + kit.js + sim.js 三層、模型全程式生成、JSON 由排程重產）
- 已有：`kit.js` 程式生成建築雛形（10 種藍圖、窗/門/屋頂/門廊/特殊件函式，Three.js 正交等角）；36 種世界建築風格參考照片（後期用）

## 三方分工的定義（本次規劃要回答「誰負責什麼」）
- **Cowork（Claude 協作模式，本對話）**：規劃與文件、研究、資料工程（文資局 ETL、對照表、精選地標 CSV）、驗收與測試計畫、排程任務（如資料重產）、跨工具交接
