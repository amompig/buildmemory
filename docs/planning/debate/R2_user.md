## B. 投票
1. 兩態——記帳城市玩家只認「平常／編輯中」。
2. 日上限 40；accuracy 300 m——容差已鎖 R+50，訊號差的人沒得作弊，只會被擋。
3. 錯誤碼＋數值＋一句人話——「再走 30 m」「明早 4 點後」是留下來的關鍵。
4. Code 先打通 3 房型再抽 schema——我要早點看到房子。
5. 第一版不做——但要說「有訊號再按」，鈕不能默默失效。
6. 通用房 ×1 色票變體、上限 3；到上限後改給碎片 1 枚——定案內可做。
7. 接受——加「被捨棄的房自動回倉庫」「拖房中不彈窗」。
8. 接受——同一張記憶卡上，「略過」和「存」一樣大。
9. 保留 70%＋進度條，道路計入填滿率——第一週就看得到進度在動。
10. 2 棟＋預鋪一條路——一棟放完就沒事做。

## C. 底線與提醒
底線：
1. 免登入先玩，登入或換裝置後一棟房、一張記憶卡都不丟。
2. 每次打卡失敗都說人話與數字；搭高鐵旅行不會被當作弊。
3. 記憶卡綁單棟：地名、日期、第 N 次、心情、一句話，拆解後仍可翻。

提醒：我刪 App 的每個瞬間都是「它沒告訴我為什麼」——任何拒絕、彈窗、灰掉的按鈕，都要有一句人話。
