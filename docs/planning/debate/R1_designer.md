## 矛盾點（他人方案彼此衝突，我選邊）
- 架構師 2/3 離線佇列 vs 資安「座標不寫 localStorage」→ 選線上，佇列需「待送出」UI 且與座標即丟衝突。
- 使用者「顯示差幾公尺」vs 資安「不洩規則」→ 選使用者，距離是玩家自身資料；冷卻只說「明天再來」。

## 無條件接受
- 工程師：Sprint 0 先 1–3 房型；bloom／移軸可選；rules.js 共用；bake＋InstancedMesh。
- 資安：不存原始座標；分享 opt-in token 剝除 lm／at；同源 API。
- 架構師：帳本每筆一列；sys: 命名空間；訪客模式雙 adapter。
- 使用者：免登入先玩；重複打卡變體＋第 N 次；半徑 150–200 m；分享圖片優先。
