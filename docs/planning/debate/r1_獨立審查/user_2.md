## 2. 我希望的遊戲流程
- **首次 60 秒**：開 App → 看到一座示範小鎮在轉 → 「這是你的空地」→ 預送 1 條路 + 1 棟家鄉通用房 → 拖一次放房 → 跳地圖頁顯示最近地標與距離。不登入、不授權也走得完。
- **出門日**：地圖上 300 m 內地標變亮 → 走到 → 按打卡 → 房子從地圖飛進小鎮的動畫 → 填一行心情 → 回鎮放房。
- **宅家日**：領簽到房 → 翻記憶卡（依日期／縣市排）→ 重排街區、畫路。
- **旅行後**：分享連結＝小鎮截圖 + 「去過 N 縣市 M 地標」，給旅伴。
- **會刪 App 的瞬間**：打卡失敗沒說明、重複房無處放、鎮上只有透天厝、要求背景定位。

```
地圖(看到亮點) → 打卡(1 秒定位) → 記憶卡(地點/日期/心情) → 小鎮(放房)
      ↑                                                    ↓
   宅家簽到 ←──────── 想再出門（下一縣市解鎖一圈） ←── 分享截圖
```

## 4. 需要使用者決定的事（最多 3 條，附你建議的預設）
1. 重複打卡給什麼：預設「記憶卡 + 同房型季節色」，碎片照舊累積。
2. 心情欄位要不要進第一版：預設要，30 字、可跳過，存在 checkins。
3. 原始經緯度存不存：預設不存，只存 landmark_id + 時間；除錯面板用本機記錄。
