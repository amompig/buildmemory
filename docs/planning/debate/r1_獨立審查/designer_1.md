# UI/UX 設計師 審查與規劃

## 1. 審查發現（最多 6 條，依嚴重度排序）
| # | 嚴重度 | 問題 | 建議（定案內可行） |
|---|---|---|---|
| 1 | 高 | 打卡成功只有「按鈕亮」，情感高點沒設計；「記憶」主題無載體 | 打卡→全幅「記憶卡」：地標名、日期、房型 3D 轉台預覽（重用 kit.js）、可選 20 字備註；房子飛入底欄倉庫。點房子看同一張卡 |
| 2 | 高 | 2D 規劃與 3D 城鎮是兩個路由，新手要切換心智模型，格座標易對不上 | 規劃改為城鎮頁內模式：相機從等角補間到正俯視、同一套 grid；2D Canvas 只當俯視渲染層 |
| 3 | 中 | 單指平移／拖房／塗格三者手勢衝突 | 手勢表：單指=平移；長按房 300ms（震動）=拖放；雙指=縮放；旋轉用按鈕 4 向快照；畫路模式單指=塗格 |
| 4 | 中 | 首次體驗空：無庫存、無路、附近可能無地標 | 首登送 iron ×1 + 中央預畫十字路；三步引導（畫路→放房→去地圖）；地圖空狀態顯示「最近地標 X km」 |
| 5 | 中 | 16×16 在 390px 寬每格約 22px，低於 44pt 觸控 | 初始 8×8 剛好；擴張後靠縮放；放置顯示放大幽靈格+吸附，底欄「確認」鈕 |
| 6 | 低 | 不合法格只靠紅色，色弱難辨；動效無開關 | 紅框+斜線圖樣+震動；對比 ≥4.5:1；按鈕 ≥44px；prefers-reduced-motion 關 bloom／補間 |

## 2. 架構提案
- `ui.js`：頁籤（地圖／城鎮／倉庫）、底欄、toast、模態，DOM 覆蓋層不進 WebGL
- `gestures.js`：手勢狀態機（pan/zoom/drag/paint），輸出語意事件
- `memorycard.js`：打卡成功卡與房子詳情卡共用
- `tokens.css`：色票／字級／間距變數，同步到 Three.js 材質色（低飽和、日夜兩組）
- `onboarding.js`：首次三步引導與空狀態
- `planner.js`：降為城鎮頁內模式，不再獨立路由

```
觸控 → gestures.js ─語意事件→ town.js/planner.js → grid
geo.js 打卡OK → memorycard.js → inventory ↘
                         validate() → ui.js 標紅/toast/底欄
```

## 4. 需要使用者決定的事
1. 規劃模式做同頁切換或獨立路由？建議：同頁切換。
2. 相機旋轉自由或 4 向快照？建議：4 向快照。
3. 放置直接落下或幽靈預覽+確認？建議：預覽+確認，設定可關。
