## 1. 審查發現（最多 6 條，依嚴重度排序）
| # | 嚴重度(高/中/低) | 問題 | 建議（定案內可行） |
|---|---|---|---|
| 1 | 高 | 畫路（2D 頁）與放房（3D 頁）拆成兩頁，手機來回切換、心智模型斷裂 | 同一 Three.js 場景，「規劃模式」= 相機切頂視 + 畫路筆刷；planner.js 只管塗格邏輯，不另開頁 |
| 2 | 高 | 塗路、拖房、平移相機都是單指拖曳，手勢衝突 | 工具列三態鎖定：看（單指平移/雙指縮放旋轉）、畫路（單指塗、雙指相機）、放房（底欄長按拖出、幽靈格綠紅提示） |
| 3 | 高 | 首啟空 8×8、無房無路，首個地標可能很遠 | 首啟即發縣市通用房 ×1（沿用每日簽到）+ 預鋪 3 格路 + 3 步引導；地圖空狀態顯示最近地標與步行分鐘 |
| 4 | 中 | 打卡只做 inventory++，缺「記憶」情感 | 成功序列：GPS 圓圈收斂→房子從地面長出→記憶卡（地標、日期、時段自動帶入、可寫 ≤40 字）→「放進小鎮」CTA；cell 加 `note` |
| 5 | 中 | 鄰路規則與 70% 擴張對玩家不可見，放完才標紅 | 拖曳中即時高亮合法格；城鎮頁頂部擴張進度條與解鎖儀式 |
| 6 | 低 | 等角畫面僅靠顏色辨識、觸控目標小、動效無法關閉 | 圖示+文字雙編碼、最小 44pt、`prefers-reduced-motion` 關移軸/bloom |

## 2. 架構提案
- `ui.js`：底部三 tab（地圖/城鎮/倉庫）、工具列、toast、模態（記憶卡、引導），不碰 3D。
- `gesture.js`：統一解析 tap/長按/pan/pinch，依模式分派給 town/planner。
- `tokens.json`：單一色票來源，同時產 CSS 變數與 Three.js 材質色；日夜兩套。
- `town.js`：渲染 + 幽靈放置 + 合法格高亮；`planner.js`：頂視相機 + 塗格；`geo.js`：定位狀態機。

```
手勢→gesture.js→mode{view|road|place}→grid(單一真相)→town.js 渲染/高亮→存檔
geo.js: idle→locating→nearby(距離)→in-range(按鈕亮)→checkin→記憶卡→inventory++→toast
```

## 4. 需要使用者決定的事（最多 3 條，附你建議的預設）
1. 規劃模式是獨立 2D 頁或同場景頂視？預設：同場景頂視。
2. 記憶卡是否開放玩家寫一句話（加 `note` 欄位）？預設：開放，≤40 字，單機不審核。
3. 色調方向：暖紙感低飽和 vs 紀念碑谷高飽和？預設：暖紙感 + 單一強調色。
