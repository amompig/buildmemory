## 1. 審查發現（最多 6 條，依嚴重度排序）
| # | 嚴重度(高/中/低) | 問題 | 建議（定案內可行） |
|---|---|---|---|
| 1 | 高 | 2D 規劃與 3D 城鎮分兩畫面，手機來回切換斷流；放房後才知不鄰路。 | 合為同一等角視角，底欄切「路／房」工具，塗路在 3D 格上即時顯示；planner.js 降為輸入層。 |

## 2. 架構提案
- ui.js：DOM 疊層（tab、倉庫抽屜、記憶卡、揭示卡、Toast、引導），只讀 state、發 intent。
- input.js：手勢狀態機（pan／zoom／paint／place／select），輸出 intent，不碰 mesh。
- town.js：依 state 渲染，含幽靈房、紅格、霧面，無邏輯。
- geo.js：定位、距離、打卡，回傳揭示卡資料。
- theme.js：色票 token，CSS 變數與 Three 材質共用，日夜切換。

```
touch → input.js(mode) → intent
  → state(grid, inventory) ─驗證(鄰路/庫存/範圍)─→ town.js
                          └→ ui.js(紅格/記憶卡/Toast)
checkin → geo.js → 揭示卡(ui) → inventory++ → mode=place
```

## 4. 需要使用者決定的事（最多 3 條，附你建議的預設）
1. 2D 規劃模式是否併入 3D 單一視角？預設：併入。
2. 放房採拖曳或點選落地？預設：點選（幽靈房），拖曳留第二階段。
3. 色票：A 低飽和粉彩＋單一強調色；B 紅磚暖色系。預設：A 為底、紅磚為強調。
