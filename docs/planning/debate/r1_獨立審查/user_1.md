# 目標玩家代表 審查與規劃

## 1. 審查發現（最多 6 條，依嚴重度排序）
| # | 嚴重度 | 問題 | 建議（定案內可行） |
|---|---|---|---|
| 1 | 高 | 走到第二間老宅又拿到同一棟 minnan，第二次就沒動力；碎片第一階段又用不到 | 同房型第 2 棟起由藍圖參數抖動（色、招牌、屋頂）出變體；碎片第一版就能換路燈、樹、紀念牌等小裝飾 |
| 2 | 高 | 「記憶」只剩地名與日期，沒有心情；點房子只是一張資料卡 | 打卡當下選 1 個心情表情（必填）+ 20 字（選填）；記憶卡顯示地名、日期、天氣、心情 |
| 3 | 高 | 首次開啟就要 Google 登入與定位權限，我會直接關掉 | 免登入送 3 棟教學房先畫路放房；第一次按「打卡」才要定位，第一次換裝置才要登入 |
| 4 | 中 | 沒出門的日子只有 1 棟鐵窗透天，沒事做就忘了 App | 同縣市通用房輪替 3 種；給「整理日」：重排、拆解、翻時間軸 |
| 5 | 中 | 8×8 一週就滿、16×16 兩個月見底，看到「滿了」就刪 | 擴張改以打卡數解鎖；滿了可「封存」開第二座（towns 加 index） |
| 6 | 中 | 定位疑慮：不知座標存不存、分享會不會露行蹤 | 打卡頁一句話：「只在按下時取一次，只存地標名」；checkins 不存 lat/lng；分享連結預設關、不含地點 |

## 2. 我希望的遊戲流程
- 第 1 分鐘：不登入，直接看到空地與 3 棟教學房，30 秒內有「我的鎮」。
- 第 1 天：地圖頁顯示最近地標與步行分鐘；差幾公尺就顯示「再走 30 m」而不是按鈕灰掉。
- 打卡：按下→選心情→房子落進倉庫→放下去時彈出記憶卡。
- 第 1 週：每天開啟拿通用房；週末小旅行拿 2–3 棟不同房；解鎖第一圈。
- 第 2 週起：重複房自動提示「變體或拆解」；時間軸頁依日期翻回憶；想分享時產生一張「小鎮截圖 + 去過的地名」圖片丟 LINE 群。
```
打開→免登入試玩→出門打卡(定位)→房+心情→放房→記憶卡
          ↑                                  ↓
      每日通用房 ←─ 沒出門 ─→ 整理/拆解/翻時間軸
```

## 4. 需要使用者決定的事（最多 3 條，附建議預設）
1. 打卡心情是否必填？預設：表情必填、文字選填。
2. 要不要存精確座標？預設：不存，只存地標 id + 日期。
3. 分享形式：圖片或唯讀連結？預設：圖片優先，連結可選。
