# 目標使用者代表 審查與規劃

## 1. 審查發現（最多 6 條，依嚴重度排序）
| # | 嚴重度 | 問題 | 建議（定案內可行） |
|---|---|---|---|
| 1 | 高 | 「記憶」沒被留下：checkins 只存經緯度與時間，沒有心情／一句話；回看房子只知道地點日期，不像回憶 | checkins 加 `mood`（5 個表情）與 `note`（≤40 字，可空）；記憶卡顯示地名＋日期＋心情＋那句話 |
| 2 | 高 | 走到地標卻拿到跟上次一樣的房，碎片第一階段又不能用 → 第二次去同地標等於白跑 | 同地標重複打卡改給「同房型不同色票/屋頂變體」（程式生成成本低），記憶卡累計「第 N 次到訪」 |
| 3 | 高 | 沒出門的日子只拿鐵窗透天厝，一週後小鎮塞滿一樣的灰房，紀念感被毀 | 每日簽到改給「道路格／小裝飾（樹、路燈、招牌）」，鐵窗厝上限 3 棟；縣市通用房型至少換色 |
| 4 | 中 | 首週太空：初始 8×8 扣掉路，1–3 棟房看起來像荒地，第二天就不想開 | 首次開啟選「我的家鄉縣市」送 3 棟＋預鋪一條路；地圖頁顯示「離你最近的 3 個地標、步行幾分」 |
| 5 | 中 | 100 m 半徑在市區 GPS 飄移下常卡「112 m」，按不亮打卡就想刪 | 精選地標半徑 150–200 m；距離 100–150 m 顯示「再靠近一點」而非灰按鈕；允許 3 次重試不冷卻 |
| 6 | 中 | 隱私：分享連結若帶出打卡座標＋日期，等於公開我的行蹤 | 分享頁只渲染小鎮；記憶卡預設不分享；設定頁有「刪除全部打卡紀錄」 |

## 2. 我希望的遊戲流程
- 第一次打開：不登入、不要求定位，先看到一座示範小鎮轉一圈（10 秒）
- 選家鄉縣市 → 得 3 棟房＋一條路 → 教學 1 分鐘：塗路、放房、點房看記憶卡
- 按「找附近地標」才要定位；列表顯示名稱、距離、會拿到什麼房
- 走到地標 → 打卡 → 選心情、寫一句（可跳過）→ 房子飛進倉庫
- 回家放房；沒出門的日子簽到拿裝飾，整理小鎮
- 想存雲端時才叫我 Google 登入，且本機存檔要合併不丟
- 分享：一鍵出圖（小鎮＋「2026.10 台南」字樣）給同行朋友，或唯讀連結

```
開啟 → 示範鎮 → 選家鄉(+3房) → 教學 → 地圖/打卡(心情+一句) → 放房 → 分享圖
                                   ↑ 每日簽到(裝飾) ──────────┘
```

## 4. 需要使用者決定的事
1. 打卡時要不要「心情＋一句話」？建議：要，可跳過，兩步內完成。
2. 每日簽到給房還是給裝飾？建議：裝飾（樹、路燈），房只從地標來。
3. 登入時機？建議：延後到第一次想分享或換裝置，之前全本機。
