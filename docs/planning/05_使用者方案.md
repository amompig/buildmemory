# 05 目標使用者方案（3 次獨立審查合併）

## 1. 審查發現
| 支持度 | 嚴重度 | 問題 | 共識建議 |
|---|---|---|---|
| 3/3 | 高 | 走到同一地標第二次只拿同一棟房；碎片第一階段用不到 = 「被欠著」 | 同房型第 2 棟起由藍圖參數抖動出**變體**（色票/季節色/屋頂/招牌）；記憶卡累計「第 N 次到訪」；1/3 碎片第一版就能換小裝飾（路燈、樹、紀念牌） |
| 3/3 | 高 | 「記憶」只剩地名與日期，沒有心情 | 打卡當下選**心情**（5 個表情；1/3 必填、2/3 可跳過）+ 一句話（20–40 字可空）；2/3 自動帶入天氣/時段；記憶卡顯示地名、日期、心情、那句話 |
| 3/3 | 高 | 一開就要 Google 登入 + 定位兩道門，還沒看到小鎮就想關 | **免登入先玩**：首啟送房 + 預鋪路（1/3 先看 10 秒示範鎮轉一圈；2/3 首啟選「家鄉縣市」）；第一次按打卡才要定位；登入延後到換裝置/想分享/首次打卡成功後提示 |
| 3/3 | 中 | 沒出門只領鐵窗透天，一週後小鎮全是同一棟灰房 | 簽到改給縣市通用池 3 選 1 / 輪替，或改給**裝飾件**（樹、路燈、小公園），鐵窗厝上限 3 棟；給「整理日」玩法（重排、拆解、翻時間軸） |
| 3/3 | 中 | 定位疑慮：不知有無背景追蹤、座標存哪、分享會不會露行蹤 | 打卡鈕旁一句「只在按下時取一次，只存地標名」；不存原始座標；分享預設不含地點與日期；可匯出與刪帳 |
| 2/3 | 中 | 100 m 半徑在市區 GPS 飄移常卡 112 m，按不亮就想刪 | 精選地標半徑 150–200 m；100–150 m 顯示「再走 30 m」而非灰按鈕；允許重試不冷卻 |
| 2/3 | 中 | 擴張 70% 第一週看不到；滿了就刪 | 擴張改以打卡數或新縣市解鎖（擴張 = 旅行足跡）；1/3 滿了可封存開第二座 |

## 2. 我希望的遊戲流程（共識）
- 首 60 秒：不登入不授權 → 看到空地/示範鎮 → 送 1–3 棟 + 一條路 → 放一次房 → 地圖頁顯示最近 3 個地標、步行分鐘、會拿到什麼房。
- 出門日：300 m 內地標變亮 → 走到 → 打卡（1 秒定位）→ 選心情/一句話 → 房子飛進倉庫 → 回鎮放房 → 記憶卡。
- 宅家日：簽到拿裝飾/通用房 → 翻記憶卡（依日期/縣市）→ 重排街區。
- 旅行後：一鍵出圖（小鎮截圖 + 「去過 N 縣市 M 地標」/「2026.10 台南」）丟 LINE/IG；唯讀連結可選。
- 會刪 App 的瞬間：打卡失敗沒說明、重複房無處放、鎮上只有透天厝、要求背景定位、換裝置資料丟。

```
開啟 → 免登入試玩 → 地圖亮點 → 打卡(心情+一句) → 放房 → 記憶卡 → 分享圖
          ↑                                            ↓
      每日簽到(裝飾/通用房) ←── 宅家 ──→ 整理/拆解/時間軸；下一縣市解鎖一圈
```

## 4. 待使用者決定
1. 心情必填或可跳過？2/3 建議可跳過、兩步內完成。
2. 每日簽到給房還是裝飾？分歧；傾向裝飾（2/3 提及）。
3. 分享形式：圖片優先（3/3），連結可選。
4. 重複打卡給變體 + 記憶卡（3/3）；碎片照舊累積。
