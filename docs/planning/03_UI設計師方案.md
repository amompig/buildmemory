## 1. 審查發現
| 支持度 | 嚴重度 | 問題 | 共識建議 |
|---|---|---|---|
| 3/3 | 高 | 2D 規劃與 3D 城鎮分兩頁，手機來回切換、心智模型斷裂、座標對不上 | **合併為同一 Three.js 場景**：規劃 = 相機補間到正俯視 + 畫路筆刷，同一套 grid；planner.js 降為塗格輸入層，不再獨立路由 |
| 3/3 | 高 | 塗格、拖房、平移、縮放共用單指，手勢衝突 | 工具列三態鎖定：看（單指平移/雙指縮放）、畫路（單指塗、雙指相機）、放房（幽靈房 + 合法格綠/紅即時高亮 + 確認）；`gestures.js` 狀態機輸出語意事件 |
| 3/3 | 高 | 首次開啟空 8×8、無房無路、附近地標可能很遠 | 首啟送通用房 ×1 + 中央預鋪一條路 + 三步引導（畫路→放房→去地圖）；地圖空狀態顯示最近地標與步行分鐘 |
| 3/3 | 高 | 打卡成功只有 inventory++，「記憶」沒有載體 | 成功序列：定位圓圈收斂 → 全幅**記憶卡**（地標名、日期、房型 3D 轉台預覽，重用 kit.js）→「放進小鎮」直入放置模式；記憶卡永久綁該棟房，點房子可再看；2/3 開放 ≤40 字備註 |
| 3/3 | 中 | 16×16 在 390 px 每格 ~22 px，低於 44 pt；解鎖圈與 2×2 佔格不明 | 相機自動 fit 已解鎖區；未解鎖格霧面；放置顯示放大幽靈格 + 吸附；1/3 擴張進度條與解鎖儀式 |
| 3/3 | 低 | 只靠顏色辨識、動效無開關、WebGL 無語意 | 紅框 + 斜線圖樣 + 震動雙編碼；對比 ≥ 4.5:1；觸控 ≥ 44 px；`prefers-reduced-motion` 關 bloom/移軸/補間；底欄/倉庫/記憶卡用 DOM 疊層 |

## 2. 架構提案（共識）
- `ui.js`：DOM 疊層（三 tab 地圖/城鎮/倉庫、工具列、底欄倉庫抽屜、記憶卡、toast、引導），只讀 state、發 intent，不碰 3D。
- `gestures.js`：tap/長按/pan/pinch → 依模式 {view|road|place} 分派語意事件。
- `memorycard.js`：打卡成功卡與房子詳情卡共用。
- `tokens`（css + json）：色票/字級/間距單一來源，同步到 Three.js 材質色；日夜兩套。
- `onboarding.js`：首次三步引導與空狀態。

```
觸控 → gestures.js → mode → grid（單一真相）→ town.js 渲染/幽靈/高亮 → 存檔
geo.js: idle→locating→nearby→in-range(按鈕亮)→checkin → memorycard → inventory++ → mode=place
```

## 4. 待使用者決定
1. 規劃模式併入 3D 同場景？3/3 建議：併入。
2. 放房手勢：長按拖曳（2/3）vs 點倉庫→點格落地（1/3）；兩者都要幽靈預覽 + 確認。
3. 色調：暖紙感低飽和 + 單一強調色（2/3 建議）vs 紀念碑谷高飽和。
4. 相機：4 向快照（1/3 建議）vs 自由旋轉。
