# 02 資安方案（3 次獨立審查合併）

## 1. 審查發現
| 支持度 | 嚴重度 | 問題 | 共識建議 |
|---|---|---|---|
| 3/3 | 高 | `/auth/google` 未定義驗證；前端直傳 id_token 當憑證可偽造/重放 | Workers 以 Google JWKS 驗 `iss/aud/exp/簽章`，用後即棄不落地；換發自家 session cookie（HttpOnly + Secure + SameSite，7 天，可撤銷）；寫入 API 檢查 `Origin` |
| 3/3 | 高 | `/share/:user_id` 可枚舉；分享含 `lm/at` 即公開行蹤 | 改 `/share/:token`（32 byte 隨機、opt-in、可撤銷、預設關閉）；回應只含 `t,id,rot`，剝除打卡地點與時間；user id 用 UUID |
| 3/3 | 高 | `checkins` 永存精確 lat/lng = 個資法位置資料，無保存期限、無刪帳 | **不存原始座標**：只存 `landmark_id, at(伺服器時間)`（2/3 加 `dist_m`）；座標在 Worker 驗完即丟、不入 log；`GET /me/export` + `DELETE /me`；保存期限（1/3 90 天、1/3 1 年）後彙整為計數 |
| 3/3 | 高 | `/checkin` 只驗距離+冷卻，DevTools 直 POST 假座標一晚刷遍全台 | 多層：Cloudflare Rate Limiting（/checkin 10–30/min/IP、/auth 10/min/IP）+ 每人每日上限（10–30 次）+ 相鄰打卡隱含速度 > 150 km/h 拒絕 + `UNIQUE(user,landmark,day)` 擋競態；dev 旗標伺服器永不信 |
| 3/3 | 中 | `PUT /town` / `dismantle` 無大小、結構、範圍限制與交易 | body ≤ 32 KB、JSON schema（256 格、enum）、n 為 1–99、D1 batch 交易、prepared statements、user_id 只取自 session |
| 3/3 | 低 | 開放資料與底圖授權標示缺位 | 關於頁 + `landmarks.json` meta：「文化部文化資產局／政府資料開放授權條款第 1 版」+ 資料集名 + 取得日；圖磚依供應商 attribution |
| 2/3 | 中 | Pages 與 Worker 分網域 cookie 問題 | Workers 掛同網域 `/api/*`（與工程師 2/3 一致） |
| 2/3 | 中 | 其他 | 拒收 `accuracy > 150 m`；`idempotency_key` 去重；CSP/HSTS、`wrangler secret`、D1 Time Travel/每日 export；縣市由伺服器判定不收客端縣市 |

## 2. 架構提案（共識）
- `worker/auth.js`（JWKS 驗證、session、`DELETE /me`、export）、`worker/guard.js`（Origin、session、限速計數、body 上限、schema，所有路由共用）、`worker/checkin.js`（距離/冷卻/速度/日上限，只寫最小欄位）、`worker/town.js`（schema + rules.js + 樂觀鎖）、`worker/share.js`（token 產生/撤銷、去識別投影）、`worker/cron.js`（保存期限彙整、token 清理）。
- 前端 `geo.js`：只在按打卡時 `getCurrentPosition` 一次，不快取、不寫 localStorage、不背景追蹤。

```
瀏覽器 ─Google id_token→ /api/auth/google ─驗 JWKS→ Set-Cookie(session)
瀏覽器 ─{lm,lat,lng,acc,key}+cookie→ guard(限速/Origin) → checkin(距離≤R→冷卻→速度→日上限)
        → D1 batch[checkins(lm,at,dist), inventory++]；lat/lng 用完即丟
匿名 ─/share/:token→ share.js ─去 lm/at→ 唯讀 grid
```

## 4. 待使用者決定
1. 是否完全不存座標？3/3 建議：不存，只存地標 id + 時間（+距離）。
2. 分享：3/3 建議 opt-in 隨機 token、預設關、只含建築配置；地標名是否顯示由使用者勾選。
3. 日上限/速度門檻：建議 20 次/日、150 km/h。
4. 帳號沿用 Dies-X：建議同一 OAuth client 加新 origin，但 D1 與 session 各自獨立（1/3）。
