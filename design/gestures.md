# BuildingYourMemory｜gestures.md v1（2026-10-21）

> 給 `gestures.js`（手勢 → 語意事件）與 `town.js`（相機、幽靈、高亮）。規則判定不在這裡，一律丟給 `shared/rules.js`。驗收：無模式殘留——任何時刻只有「看」或「擺放」一態，且畫面上一定看得出是哪一態（橫幅在 = 擺放）。

## 1. 兩態狀態表

| | 看（view） | 擺放（place） |
|---|---|---|
| 怎麼進 | 啟動預設；擺放按「完成」 | F1「擺放」鈕；F5「放進小鎮」；F7 卡片「放」 |
| 怎麼出 | 切 tab（本態不變） | 只有橫幅「完成」；切 tab 等同先「完成」 |
| 畫面標記 | 底欄三 tab、右下轉向 / 看全鎮 | 頂部橫幅「擺放中・復原・完成」、底欄 = 倉庫抽屜 |
| 單指 tap | 房子 → 迷你記憶卡（F6）；空處 → 無 | 選道路：塗 / 擦該格；選房型：把幽靈移到該格並嘗試落房 |
| 單指 pan | 相機平移 | 選道路：連續塗 / 擦（經過的格）；選房型：幽靈跟著走，放手 = 嘗試落房 |
| 單指長按（400 ms） | 房子 → 直接進擺放並預選它（搬家） | 已放的房子 → 拿起（變幽靈） |
| 雙指 pinch | 縮放（0.6×–2.2×） | 縮放 |
| 雙指 pan | 相機平移 | 相機平移（**雙指永遠是相機**，塗路中亦同） |
| 旋轉手勢 | 不支援（4 向快照鈕） | 不支援 |
| 右下「轉向」 | 南 → 西 → 北 → 東 循環，320 ms 補間 | 同左；塗路（俯視）時停用 |
| 右下「看全鎮」 | fit 解鎖視窗 | 同左 |
| 相機俯仰 | 等角固定 | 選道路 = 正俯視（補間 320 ms）；選房型 = 回等角 |

## 2. 語意事件（gestures.js 只發這些）

| 事件 | 參數 | 發生時 |
|---|---|---|
| `camera.pan` | dx, dy | 看態單指 pan；任何態雙指 pan |
| `camera.zoom` | scale, cx, cy | 雙指 pinch |
| `camera.rotate` | dir ∈ {S,W,N,E} | 轉向鈕 |
| `camera.fit` | — | 看全鎮鈕 |
| `camera.topdown` | on: bool | 擺放態切換道路 / 房型 |
| `cell.hover` | idx | 擺放態幽靈經過的格（節流 1 幀） |
| `cell.commit` | idx | 擺放態放手 / tap |
| `cell.paint` | idx[] | 道路塗，pan 經過的格批次 |
| `cell.erase` | idx[] | 道路擦 |
| `house.pick` | idx | 看態 tap 房子 |
| `house.lift` | idx | 長按已放房子 |
| `mode.enter` / `mode.exit` | source | 進出擺放態 |

`edit.js` 收到 `cell.*` 後呼叫 `rules.canPlace / canPaintRoad / canEraseRoad`，結果回 `town.js` 畫幽靈顏色與回饋；gestures 不知道規則。

## 3. 門檻與參數

| 項目 | 值 |
|---|---|
| tap 判定 | 位移 < 8 px 且 < 250 ms |
| 長按 | 400 ms，位移 < 8 px；觸發時震動 10 ms |
| pan 起算 | 位移 ≥ 8 px |
| 塗路取樣 | pointermove 每格一次，格子由射線求交；跨格補線（Bresenham）避免快滑漏格 |
| 幽靈吸附 | 幽靈中心到格中心 120 ms 補間；同格不重算 |
| 雙指優先 | 第二指落下 → 立刻取消單指塗 / 幽靈，交給相機；第二指抬起後 150 ms 內不恢復單指動作 |
| 縮放範圍 | 0.6×–2.2×，超出回彈 200 ms |
| 邊界 | 相機平移夾在解鎖視窗 + 2 格 |
| 復原 | 單步，最多 20 步，只在擺放態；完成後清空 |

## 4. 回饋（三重編碼）

| 狀態 | 視覺 | 觸覺 | 文字 |
|---|---|---|---|
| 可放 | 格底 `ok` 45% + 幽靈房 60% 不透明 | — | — |
| 不可放 | 格框 `danger` 2 px + 45° 斜線（`cell-bad`）+ 幽靈房 35% 紅 | 震動 10 ms | toast：`town.cell_locked` / `cell_occupied` / `cell_no_road` |
| 塗路成功 | 格即刻變路色 | — | — |
| 擦路被拒（orphan） | 該格紅框 + 斜線 400 ms | 震動 10 ms | toast `town.road_orphan` |
| 落房成功 | 落房動效（§5） | 震動 10 ms | — |
| 鎖定格 | 霧色（`locked_fog`），不響應 | — | 點 2 次以上才 toast `town.cell_locked` |

顏色都配形狀（框線 / 斜線）與震動，色弱也分得出；`prefers-reduced-motion` 不關震動，`navigator.vibrate` 不支援時靜默。

## 5. 動效

所有時長來自 `tokens.css` 變數；`prefers-reduced-motion: reduce` 時全部變 0 ms，改用「立即到位 + toast」。

| 動效 | 時長 | 曲線 | 內容 | reduced-motion 替代 |
|---|---|---|---|---|
| 幽靈吸附 | 120 ms | `--ease` | 幽靈從手指位置滑到格中心 | 直接出現在格中心 |
| 落房 | 240 ms | ease-out | 房子從 1.08× 縮到 1×、y 從 +0.3 格落地；落地瞬間格子微閃 ok 色 1 幀 | 直接出現 |
| 拿起 | 160 ms | ease-out | 房子升 0.3 格、變 60% 透明 | 直接變幽靈 |
| 抽屜升降 | 220 ms | `--ease` | 倉庫抽屜 / 記憶卡從底部升起；底欄三 tab 淡出 | 直接顯示 |
| 相機 4 向 | 320 ms | `--ease` | 繞鎮中心轉 90°，高度不變 | 直接切 |
| 俯視補間 | 320 ms | `--ease` | 俯仰角等角 → 90°，同時格線 alpha 0.3 → 1 | 直接切 |
| 解鎖儀式 | 900 ms | ease-out | 新一圈格子由中心向外依序從霧色亮起（每格延遲 12 ms），最後擴張卡數字跳動 | toast `town.unlock_ceremony`，格子直接亮 |
| 打卡成功 | 見 memorycard_storyboard.md（Sprint 1） | | 定位圈收斂 → 房子長出 → 記憶卡升起 | 記憶卡直接升起 |
| toast | 進 160 ms / 停 3 s / 出 120 ms | | 底欄上方升起 | 直接出現，停 4 s |

原則：一次只有一個主動效在跑；相機補間中忽略新的 tap（pan 仍可）；動效不阻擋資料寫入（落房先寫 store，再播動畫）。
